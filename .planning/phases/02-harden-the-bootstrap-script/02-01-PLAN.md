<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User shell profile -> script writes | The script writes persistent shell config; incorrect targeting can corrupt startup behavior. |
| External installers -> local execution | Remote install scripts and package indexes are untrusted inputs crossing into local execution. |
| Managed Python env -> pip operations | Fallback writes to managed Python environments can alter host-level packages. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | `detect_shell_rc` / profile writes | mitigate | Route all persisted shell edits through `append_to_rc_once` and add `.profile` fallback only for unknown shell contexts. |
| T-02-02 | Denial of Service | bootstrap dependency installs | mitigate | Keep fail-fast checks, explicit warnings, and deterministic ordering so failures stop early with actionable output. |
| T-02-03 | Elevation of Privilege | managed Python fallback path | accept | Maintain fallback for fresh WSL reliability per D-05, with explicit warning text and recommendation to prefer venv/conda. |
| T-02-04 | Repudiation | operator understanding of optional semantic deps | mitigate | Add concise, explicit consequence prompt and documentation note so install choices are auditable and intentional. |
</threat_model>
